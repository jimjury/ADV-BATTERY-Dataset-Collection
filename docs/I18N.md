**English:** All seven README files include the same complete resource table and source links. Names are kept in the recorded English form for traceability. Detailed documentation is primarily Chinese or bilingual. The V2 web application itself has **not** been translated into seven languages.

## 2. 单一数据源 / Single source of truth

- All counts, source URLs, dataset IDs, tags and paper relations come from the **same** `data/*.json` records and are **not** translated or manually re-entered for each language.
- `scripts/build_public_index.py` generates all seven READMEs. Additional strings live in `scripts/readme_locales.py`.
- `README.md` and `README_EN.md` use the existing canonical generator; the other five READMEs use the localized renderer, but all operate on the same catalogue snapshot.
- The historical records, licensing statements, link-verification limitations and provenance are intentionally preserved.

## 3. 维护流程 / Updating translations

After updating the approved catalogue (or the public JSON snapshot), run:

```bash
python scripts/build_public_index.py --write
python scripts/build_public_index.py --check
python scripts/validate_public_index.py
```

`--write` recreates the generated READMEs and updates the catalogue snapshot date. Do not manually edit generated resource rows; such changes will be overwritten. For improved translations, edit the locale strings in `scripts/readme_locales.py` and rerun the generator.

Before merging, verify that: every language has the same number of table entries as `data/catalog_info.json`, language links resolve, the official dataset source URLs remain unchanged, and no third-party raw data or copyrighted papers are committed.

## 4. 翻译纠错 / Suggesting improvements

Translation suggestions are welcome via the repository's [Issues](https://github.com/jimjury/ADV-BATTERY-Dataset-Collection/issues) or a pull request. Please identify the language, exact source text, your proposed wording and, for technical terminology, a short explanation. Do not translate DOI values, dataset identifiers, source URLs or dataset names into unofficial claims.

## 5. 许可与来源 / Licensing and provenance

The repository is a **directory of metadata and links**; it does not redistribute third-party raw datasets. Original data owners determine access, licensing and permitted uses. See [`NOTICE.md`](../NOTICE.md) and cite the original dataset provider and linked publications in research.
